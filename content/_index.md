FMAAI 2027, the Workshop on Formal Methods for Agentic AI, takes place on Monday, July 19, 2027, in Amsterdam, Netherlands, co-located with [CAV 2027](https://conferences.i-cav.org/2027/).

## Scope

FMAAI bridges formal methods and agentic software systems: capturing critical behavior in formal models and specifications (temporal logics, state machines, invariants) so that AI agents can operate with verifiable guardrails for safety, security, and privacy.

Topics include auto-formalization, neurosymbolic observability, agent guardrails, deterministic simulation for agents, workflow and state machine inference, runtime verification and logic-grounded planning, and agent operating systems and proof-carrying code.
